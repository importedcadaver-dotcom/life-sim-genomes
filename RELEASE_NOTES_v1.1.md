# v1.1 — Evolvable Regulatory Life

- Optional genetic regulation through a bounded 16-instruction genome, with neutral instructions, threshold gates, recurrent-within-sequence register influences and environment-dependent phenotype expression.
- Chromosome groups inherit in two-parent and one-parent reproduction. Mutation can insert, modify, duplicate, delete and rearrange genes; chromosome fission and whole-chromosome copying can form new chromosome groups.
- Physiological outputs affect real movement, metabolism, digestion, sensing, growth, and reproduction costs. Interpreter cannot execute arbitrary source code or invent physical rules not supported by the ecology.
- New DNA inspector tab shows each selected creature's regulatory program and real-time expression, including dead archived creatures.
- Genome Detective mini-game; evidence-backed gene/chromosome milestones; DNA Spark now affects regulatory DNA and remains logged as an intervention.
- Optional disk-backed SQLite history with integrated self-contained checkpoint snapshot; previous saves remain readable.
- Experiment 010: controlled multi-seed preliminary result is mixed, not evidence of a consistent fitness advantage.
- Historical genetics and neural-only behavior remain default in headless runs; new viewer worlds start with regulatory genetics, with `--no-regulation` and `--legacy-genetics` switches.
- Real Windows graphical QA remains unverified in this environment. Run `run_graphical_qa_windows.bat` on Windows.
