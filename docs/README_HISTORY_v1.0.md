# The Accidental Biosphere — v1.0: Genetic Life

**An evolving digital ecosystem you can observe, inspect, and experiment with.** This is a research-first artificial-life prototype with a growing interactive Pygame observatory. Its inhabitants are not scripted animals or proven intelligent beings.

**New genetics-enabled viewer worlds:** Every little creature inherits 16 controller weights **plus 12 biological loci and variable gene-copy numbers**. DNA now affects body size, feeding, energy costs, sensory reach, maturation, lifespan, reproduction and visible pastel markings. Baby organisms grow toward their own genetically specified adult size. Random biological mutations and gene duplications/deletions can spread across generations when their carriers survive and reproduce. There is **no hand-written survival policy** for an organism; offspring and death are driven by the simulated ecology.

The older 16-weight neural-only experiment mode remains reproducible and is still the default for the headless `run` command unless `--genetics` is supplied. Previous experiments and older checkpoints remain intact.

## New in v1.0 — DNA, inheritance, mating and evolutionary testing

Click a creature, then press **G** or click **DNA** at the top of the pink observatory. Inspect its 12 alleles, per-gene copy numbers, inherited phenotype multipliers, mutation count, and up to two biological parents. Creature size, coat color and white spots are now inherited, not merely cosmetic colors derived from neural weights.

There are **three reproduction modes**: `mixed` (locally paired mating where possible, otherwise clonal budding), `sexual` (requires a second eligible nearby parent) and `asexual` (single-parent offspring). Two-parent children inherit individual genes from both parents, then may experience neural, allele or copy-number mutations. Each birth costs actual parental energy. No arbitrary "bottom 50%" are deleted.

**Cheats:** Press `Q` for the Sugar Rush cheat menu. New option **5 — DNA Spark** applies random genetic changes to your selected creature and saves an explicit experimental-intervention flag. The earlier candy-food, energy-cupcake, baby-clone and immortality cheats remain available.

**Experimental tools** (purely local CPU, no paid APIs):

```powershell
# Headless DNA evolution with birth/death logs and a saved reproducible world
python -m biosphere run --genetics --steps 2000 --seed 19 --events --output results/my_genetic_world

# 12 independent matched-seed mutation-on/off studies, with CSV gene timelines
python -m biosphere genomics --seeds 12 --ticks 1600 --workers 4 --output results/my_genetics_study

# Verify biological selection versus neutral inherited marker drift
python -m biosphere gene-selection --seeds 12 --ticks 700 --output results/my_selection_assay

# Watch sexually reproducing little creatures (starts a new DNA-enabled world)
python -m biosphere view --reproduction-mode sexual
```

All historical `*.npz` checkpoints can be opened, but a historical checkpoint remains in its original neural-only mode. Start a **new** viewer world to enable biology. This prevents older research results from being silently invalidated.

Read the [full genetics and model guide](docs/GENETICS_v1.0.md), [Experiment 009](docs/EXPERIMENT_009.md), and [v1.0 release notes](RELEASE_NOTES_v1.0.md). **Important limitation:** this is *bounded artificial genetics* (12 known body loci, 0–3 copies/locus), not self-inventing molecular DNA, speciation, or open-ended genome architecture. Native Pygame window QA still needs to run on Windows; our image previews are diagnostic drawings, not graphical-runtime screenshots.

## Quick start on Windows

1. Install **Python 3.10+**. If possible, select **Add Python to PATH**.
2. Extract the complete downloaded ZIP to a writable folder.
3. Double-click **`run_windows.bat`** to install the required Python packages and open the viewer. It supports both `py -3` and `python` launchers.

Alternatively, in a command prompt inside the extracted folder:

```powershell
python -m pip install -r requirements.txt
python -m biosphere view
```

To watch an actual evolved sparse-world population instead of starting with random founders:

```powershell
python -m biosphere view --resume results/experiment_004/checkpoints/seed_701_islands.npz
```

**Note:** This is Python source, not a compiled Windows `.exe`. This environment could not install Pygame, so native graphical performance and Windows compatibility remain unverified. The **v0.9 diagnostic screenshots** in `results/qa_preview/` are generated by the actual viewer drawing logic using a Pillow-backed rendering adapter, **not** the SDL/Pygame backend. For genuine Pygame QA on your Windows computer, double-click `run_graphical_qa_windows.bat`; it will generate actual Pygame screenshots and an automated check report.

## New in v0.9: Pink Living Observatory

The organisms now look like **cute pastel berry bugs** (pink, lavender, peach, mint) instead of triangular darts. This is decorative art derived deterministically from one inherited gene; body traits do not affect their simulated biology. The observatory itself is now plum-and-pink.

Use **Q** for *Sugar Rush Cheats*, **E** for two observational minigames (*Berry Hunt* and *Speed Detective*), **D** for the bookmarkable specimen Chronicle with read-only movement replay, and **W** for an interactive matched A/B habitat lab. All four are clickable across the top of the map. The lineage tree also supports offspring pagination. Cheats change ecology and visibly mark the saved world as **INTERVENED**. Minigame scores/chronicle tracks are saved in a checkpoint-sidecar `*.observer.json` when pressing `S`.

The new science report **Experiment 008** compares matched evolutionary populations trained with and without food sensors. In 12 seed pairs, the average primary advantage for sensor-trained genomes was only **+0.082 offspring per founder**, and just five pairs were positive. This is *not evidence of a consistent training advantage*. Read [`docs/EXPERIMENT_008.md`](docs/EXPERIMENT_008.md) and inspect the raw 48 trial records in `results/experiment_008/trials.csv`.

## v0.7 foundation: The Living Observatory

The observatory is now slower and more legible by default: **10 simulation ticks per real second**, with independent render pacing and single-stepping. Birth and death map markers last 4.5 actual seconds. Select a specimen to track its real life; enable automatic pause on selected offspring/death events (`P`). The selected organism remains inspectable after death rather than disappearing.

**Saved individual histories** now include birth/death tick, direct offspring, first feeding, first reproduction, lifetime harvested food, distance moved, peak energy, and cause of death. Select an individual to start sampling its real path and energy (up to 240 samples per tracked individual). These details are preserved when the world is saved. A paginated, scrollable archive of extinct organisms (`A`), clickable family graph (`Y`) and microscope (`O`) make the evolving population easier to understand. Microscope values come from the actual 16 inherited neural weights and eight sensory inputs, not scripted personalities.

Action controls are two rows instead of squeezed into one; sidebar tabs always expose the latest real events, specimen details or family connections. Press `R` or `I` **twice** within six seconds to confirm a destructive restart. `S` saves a checkpoint and screenshot. The GUI needs graphical runtime QA; see [`docs/GRAPHICAL_QA_v0.7.md`](docs/GRAPHICAL_QA_v0.7.md).

### Experiment 007: reproductive consequences of sensing food

The new `fitness` command reuses the archived Experiment 004 genomes and lets organisms eat, reproduce, die and compete over 350 ticks while selectively removing or mirroring food-sensor inputs. Eight training seeds × two genome groups × two speed conditions × three sensory conditions = **96 matched ecological colony trials**. In expensive-island-trained populations, enabling their normal food cues produced **0.800 direct children per original founder**, versus **0.378 with the food inputs removed** (natural motor speed; the difference was positive in all eight independently trained seeds). With speed fixed to 0.60 the means were 0.817 versus 0.442. Final population did *not* show a comparably consistent advantage. This supports a reproductive effect of the inherited cue responses under test conditions, **not intelligence or reliable target-directed navigation**.

See [complete Experiment 007 methods and caveats](docs/EXPERIMENT_007.md), the raw [`results/experiment_007/trials.csv`](results/experiment_007/trials.csv) and [`RELEASE_NOTES_v0.7.md`](RELEASE_NOTES_v0.7.md).

```powershell

python experiments/plot_fitness.py
```

## Experiment 006: is turning actually food-contingent?

**New in v0.6:** a controlled trajectory laboratory, not a scripted AI behavior or a new Pygame interface. It reuses the original 16-weight controllers and archived seed-701–708 evolutionary populations in motor-only experiments. Food/energy feedback is suppressed and speed is held constant to expose the effects of sensory cues themselves.

- **384 matched trials:** 8 training seeds × 4 genome groups × 2 start conditions × 6 cue/motor interventions; 36 controllers per trial, 90 steps each.
- **Near-patch search:** expensive-island-trained controllers entered any core in 37.2% of probes with accurate cues, 9.4% with absent cues, and 9.7% with displaced cues. Straight movers reached a core 85.8% of the time.
- **Core residence:** the same evolved controllers spent 75.4% of their time inside a core with accurate cues and 79.0% with barren cues. Circling persists without resource information.
- **Evolutionary comparison:** the accurate-cue search benefit exceeded that of founders by 15.3 percentage points (7/8 seeds positive; exploratory descriptive interval 7.6–22.2 points).
- Actual positions/angles, core overlap, cue-dependent turn responses and seed-level contrasts are saved. Hypothetical resource exposure is *not* reported as actual food harvested.

Read [Experiment 006](docs/EXPERIMENT_006.md) and [v0.6 release notes](RELEASE_NOTES_v0.6.md). Run:

```powershell
python -m biosphere trajectory --seed-start 701 --seeds 8 --ticks 90 --trained-results results/experiment_004 --output results/my_trajectory_replay
python experiments/plot_trajectory.py
```

The visual plot script reads the included canonical `results/experiment_006` data by default. The new experimental study is **headless**, while the familiar interactive Pygame viewer continues to work from the unchanged `view` command if Pygame is installed.

## Experiment 005: find a food patch or remain in one?

The v0.4 studies found that removing steering improved direct target encounters but steering improved resource collection once food was available. v0.5 separates **search** from **residency** with two matched assays.

- **256 experimental trials:** eight independent training seeds × four genome groups × two starting conditions × four motor interventions.
- Each trial tracks 36 organisms, all at externally fixed forward speed 0.60, for 75 ticks, without reproduction or mutation.
- Costly-island-trained organisms entered a food core from a distant start in **33.7%** of normal-controller cases versus **74.3%** with steering disabled.
- When they began inside a core, normal controllers spent **80.9%** of the assay inside a core, versus **14.7%** with steering disabled. Their average intake was **1.351** versus **0.543** food units/organism/tick.
- Critically, removing food sensors did **not** abolish local residency: **83.0%** occupancy in food-blind controllers. **Persistent turning may be responsible, not deliberate food-seeking.**

See [`docs/EXPERIMENT_005.md`](docs/EXPERIMENT_005.md) for complete procedure, seed-paired contrasts, caveats and limitations. This was an **exploratory analysis of existing evolved checkpoints**, not independently preregistered evidence of intelligence or planning.
